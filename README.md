# MSME RAG Project

An MSME (Micro, Small and Medium Enterprises) advisory assistant built as a **Retrieval-Augmented Generation (RAG)** system. The project uses a **FastAPI backend**, a **Streamlit frontend**, **ChromaDB** for vector storage, **Ollama embeddings**, and **Groq / OpenRouter** for LLM responses. It also includes a **Tavily web-search fallback** for time-sensitive questions.

---

## Overview

This project answers questions related to:

- MSME definitions and classification
- Government schemes and incentives
- Registration and compliance
- Funding, loans, subsidies, and credit guarantees
- Startup policies and innovation support
- Policy analysis and MSME competitiveness

The system first tries to answer from the local knowledge base (`ragdb`). If the retrieved context is not enough, it can optionally search the web for newer information. The final answer is generated by an LLM using the retrieved context and any live context.

---

## Key Features

- FastAPI backend for chat and health endpoints
- Streamlit UI for an interactive chat experience
- ChromaDB vector store for semantic retrieval
- Ollama embeddings with `nomic-embed-text`
- Context sufficiency check before web search
- Optional Tavily search for recent updates
- Guardrails for basic PII and prompt-injection blocking
- Persistent manifest-based PDF ingestion
- Docker support for backend + frontend deployment

---

## Architecture

```text
Streamlit UI
    ↓
FastAPI Backend
    ↓
Guardrails
    ↓
Router
    ↓
Retriever (ChromaDB + Ollama embeddings)
    ↓
Context Sufficiency Check
    ↓
Optional Tavily Web Search
    ↓
LLM Answer Generation
```

The system is designed as a Streamlit frontend talking to a FastAPI backend. The backend performs routing, retrieval, context checking, optional web search, and final answer generation.

## Important Configuration

The main settings live in `config.py`. Your current defaults include:

- `ollama_base_url = http://localhost:11434`
- `embedding_model = nomic-embed-text:latest`
- `chroma_persist_dir = ./ragdb`
- `pdf_dir = ./data/pdfs`
- `ingestion_manifest_path = ./ragdb/ingestion_manifest.json`
- `retrieval_top_k = 8`
- `chunk_size = 1000`
- `chunk_overlap = 150`
- `run_ingestion_on_startup = True`

The current prompt templates enforce:
- MSME vs General routing
- Conservative context sufficiency checks
- Strict answer generation from provided context only

## Local Setup

### 1) Create and activate virtual environment

#### Windows PowerShell
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

#### Linux / macOS / WSL
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2) Install dependencies
```bash
pip install -r requirements.txt
```

### 3) Start Ollama
```bash
ollama serve
```

### 4) Pull the embedding model
```bash
ollama pull nomic-embed-text
```

### 5) Run FastAPI
```bash
uvicorn main:app --host 127.0.0.1 --port 8000
```

### 6) Run Streamlit
```bash
streamlit run streamlit_app.py
```

## Docker Notes

- The project is designed to use the existing `ragdb` via a mounted volume.
- Do **not** bake `ragdb` into the image unless you intentionally want a self-contained immutable build.
- Each user running the project will need their own API keys.
- If running in Docker, the Streamlit app should point to the API container hostname (`http://api:8000/chat`) rather than `127.0.0.1`.

## Ingestion

If you need to rebuild the vector database from PDFs:

```bash
python -u -c "from ingestion import PDFIngestionPipeline; print(PDFIngestionPipeline().ingest_all())"
```

The ingestion pipeline:

- loads PDFs from `data/pdfs`
- chunks text
- generates embeddings
- stores chunks in ChromaDB
- updates `ragdb/ingestion_manifest.json`

It uses chunk hashing and file hashing to skip already processed content. The manifest keeps track of PDF file hashes and chunk hashes.

## Troubleshooting

### `GROQ_API_KEY is required for routing`
Add the key to `.env` and ensure it is passed into Docker or your local environment.

### `Could not connect to FastAPI server`
Check:
- API container is running
- Streamlit URL points to `http://api:8000/chat` in Docker
- FastAPI is reachable from the Streamlit container

### Retrieval is slow
- Check Ollama is running
- Verify ChromaDB exists in `ragdb`
- Reduce `retrieval_top_k` if needed

### Need to update documents
- Add new PDFs to `data/pdfs`
- Re-run ingestion if required
- If you remove or replace PDFs, rebuild `ragdb` for a clean vector store
